# とどメモ

ずぼらな人のための、書きっぱなしでいい TODO アプリです。

**https://yqqqchqn31.github.io/todomemo/**

## すぐ試す

スマートフォンのブラウザでそのまま開けます（インストール・ログイン不要）。

1. 初めて開くと、トドが「今日はなんにもしない〜」の画面が出ます。
2. **「サンプルを入れて試してみる」** を押すと、全部の機能を試せる見本のタスクが入ります。
3. 最初の画面に戻すときは、「すべて」タブの一番下の **「データをすべて消して、最初の状態に戻す」** を押します。

ホーム画面に追加すると、アプリのように全画面で開けます（iPhone は Safari の共有ボタン、Android は Chrome のメニューから「ホーム画面に追加」）。

## ターゲットとコンセプト

### 想定している人

- 思いついたことをすぐ忘れてしまう
- TODO アプリを入れても、分類や整理が続かずに使わなくなる
- 終わらなかったタスクが溜まっていくのを見て、つらくなる

### コンセプト

1. **書きっぱなしでいい** … 書くときに何も決めなくていい。整理は気が向いたときに
2. **整理は少なく** … 行き先は「今日・いつか・とりあえず」の3つだけ
3. **責めない** … 終わらなかった日も、期限が過ぎた日もある前提でつくる

名前の「とど」は、TODO とトドをかけています。

## 操作

| やりたいこと | 操作 |
| --- | --- |
| タスクを書く | 画面下の欄に書いて Enter |
| 完了にする | 丸をタップ、またはタスク名の上を右になぞる |
| 細かく決める | タスク名をタップしてシートを開く（蛍光ペン・いつやる・ラベル・期限・くり返し・削除） |
| タブを移る | 画面を左右になぞる、またはタブをタップ |
| 「とりあえず」を片付ける | 「すべて」タブの上の「整理する」 |
| 取り消す | 操作のあとに出るお知らせの「元に戻す」 |

## 使いやすさのための工夫

### 書くときに迷わない

- 入力欄は画面の一番下、親指で届く位置。書いたタブがそのまま行き先になるので、書くときに選ぶものはありません（ラベルのタブで書けばラベルも自動で付きます）。
- キーボードが出ても入力欄と見出しが隠れないようにしました。日本語変換の確定の Enter で誤って追加されることもありません。
- 一度開けば、電波がなくても開いて書けます。

### 整理をがんばらなくていい

- 行き先は「今日・いつか・とりあえず」の3つだけ。何も決めていないものは「未整理」ではなく「とりあえず」と呼んでいます。
- 整理モードでは「とりあえず」が1枚ずつ出てきて、ボタンを1回押すだけで次に進みます。途中でやめても大丈夫です。
- 今日タブには今日の分だけを出し、明日以降は「すべて」で見られます。

### 責めない

- 終わらなかったタスクは、翌朝「そういえば、これどうする？ / やる日が過ぎたものが3こあるよ」とカードにまとめ、1タップで今日かいつかへ移せます。見せるのは3件までです。
- 「とりあえず」に14日置いたままのものは「眠っているもの」にそっとしまい、目に入らないようにします。まとめて手放すこともできます。
- 期限が過ぎても赤く光らせず、落ち着いた色で日付を出すだけ。くり返しは、サボっても次の回が溜まりません。

### 触って気持ちいい・失敗してもいい

- タスク名をなぞると、鉛筆で線を引くように完了できます。
- 完了・移動・削除などのあとには必ず「元に戻す」が出るので、確認ダイアログは出しません。
- 大事なものは蛍光ペンを引くと一覧の上に来ます。期限は「あと2日」のように出します。

### だれでも使える

- ボタンは指で押しやすい大きさにし、読み上げ機能でも操作できるようにしています。
- 文字は小さくても読みやすい明るさの差にし、「視差効果を減らす」設定ではアニメーションを減らします。

## 実行環境

| 項目 | 内容 |
| --- | --- |
| 公開URL | https://yqqqchqn31.github.io/todomemo/ |
| 動作確認 | iPhone / Safari、Android / Chrome、PC / Chrome |
| ホスティング | GitHub Pages（`main` に push すると GitHub Actions で自動公開） |
| データの保存先 | 端末のブラウザ（localStorage）。サーバーには送りません |
| 使用技術 | React 19 / TypeScript 7 / Vite 8 / Tailwind CSS 4 / date-fns / sonner / vite-plugin-pwa |

- データは端末のブラウザの中だけに保存されます。別の端末とは共有されません。
- オフライン対応のため、新しい版は「次に開いたとき」から反映されます。古いままなら一度閉じて開き直してください。

### 手元で動かす

Node.js 22 以上が必要です。

```bash
git clone https://github.com/yqqqchqn31/todomemo.git
cd todomemo
npm ci
npm run dev      # 開発用サーバー（http://localhost:5173/todomemo/）
npm run build    # 型チェックと公開用ファイルの作成（dist/）
npm run preview  # 公開用ファイルを確かめる
```
